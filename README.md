# n8n POC - Node.js Automation Flow

This is a **Proof of Concept** project demonstrating how to integrate **n8n workflow automation** with a **Node.js backend**.

## 🎯 What This POC Does

- ✅ Receives webhooks from n8n workflows
- ✅ Processes automation data
- ✅ Triggers n8n workflows programmatically
- ✅ Logs and tracks workflow execution
- ✅ Provides REST API for workflow management

## 🚀 Quick Start

### Prerequisites
- Node.js 14+ installed
- Docker (optional, for running n8n locally)
