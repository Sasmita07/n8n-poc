# Issue: Phase 14 – Multi-Tenant Support

## Summary

Add multi-tenant architecture to support organizations, teams, and permissions.

## Goals

- Support multiple users and organizations
- Add team workspaces
- Implement permissions and tenant isolation

## Acceptance Criteria

- Users are scoped to organizations or tenants
- Teams can manage workflows within their workspace
- Permissions enforce data and workflow access boundaries

## Notes

This phase supports scaling the platform for multiple customers and teams.
