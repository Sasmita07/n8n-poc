# Issue: Phase 3 – AI & Agentic Workflows

## Summary

Integrate AI decision-making into workflows to enable agentic automation.

## Goals

- Add AI model integration for workflow execution
- Build workflows that use AI agents for decision making
- Support HTTP requests and database interactions based on AI output

## Acceptance Criteria

- Workflows can call AI models during execution
- AI-driven decisions can route workflow branches
- Data can be stored or updated in a database from AI workflow steps

## Notes

Potential AI integrations include OpenAI, Anthropic, and local LLMs.
